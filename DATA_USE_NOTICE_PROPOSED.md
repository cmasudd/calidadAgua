# Aviso propuesto de uso de datos — en revisión

> **Borrador para revisión jurídica.** ODbL-1.0 y la licencia de contenidos aún
> no han sido aprobadas para este proyecto.

Los datos se obtienen mediante sensores ambientales y se publicarán para
consulta, investigación, educación y reutilización. Pueden presentar
incertidumbre, datos faltantes, interrupciones o correcciones posteriores.

Para interpretarlos deben considerarse, al menos, la ubicación, fecha y hora,
unidad, calibración, mantenimiento, estado de comunicación y metadatos de
calidad disponibles. Una observación aislada no debe interpretarse sin su
contexto temporal y espacial.

Las referencias a normas chilenas serán orientativas y declararán la norma,
ámbito territorial, uso y parámetro comparado. La plataforma indicará cuando
no exista una referencia aplicable. El resultado mostrado no equivale a una
evaluación oficial de cumplimiento normativo.

Si se aprueba el esquema propuesto, la base se publicará bajo ODbL-1.0 y los
usos públicos deberán conservar una atribución visible. La licencia aplicable
a los contenidos individuales todavía debe ser determinada.
